# Specs

Store active task-local records for real repository work here.

Use `specs/<topic>/` only while a task needs persistent research, decision,
design, planning, or validation artifacts. A roadmap stage's library research
lives in `specs/<stage-topic>/research/synthesis.md` while the stage is being
implemented. After completion, move durable decisions into the owning
document (`docs/roadmap.md`, an architecture leaf, or code comments) and
delete the bundle; Git keeps the history.

Do not create synthetic or archival bundles as examples.
