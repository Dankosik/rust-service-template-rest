# T5 — Native S3 candidate budget propagation

Outcome:
The pinned Smithy client propagates its existing connector timeout to native
Hyper TCP connection selection, giving healthy later candidates an opportunity
inside the same operation/connect budget without new retries or finality rules.

Consumes:
- [Specification fallback decision](../spec.md#conditional-address-fallback-decisions).
- [Design](../design/transport.md#s3-native-fallback) and [source custody](../design/transport.md#source-and-file-custody).
- [Execution boundary](execution-boundary.md) — shared carrier writer and final assembly.

Provides:
- Pinned aws-smithy-http-client 1.4.2 repair, complete object-storage profile/delivery custody, distinguishing tests and accurate streaming/rotation guidance.

Boundary:
Vendor checksum-verified published source with licenses, revision/archive
identity, exact diff and retirement. Runtime source delta stays in native
client.rs::base_connector_with_resolver; copy configured timeout into Hyper,
retaining outer timer, TLS/DNS/pooling, SDK attempts and credential HTTP use.
The existing S3 3.1 s setting is unchanged. Preserve inner I/O versus outer
connector-timeout classification, operation deadline and mutation OutcomeUnknown.
No custom HttpClient, provider upgrade or whole-stream cap.

Mutable owners:
- New `vendor/aws-smithy-http-client/`, its native tests and PATCHES.md; existing object-storage tests/fixtures as needed for accepted behavior.
- Object-storage slices of root Cargo manifests/lock, Docker context/image sources, `scripts/lib/template_profiles.json`, changed-surface classifier and existing initializer/classifier fixtures.
- `docs/object-storage.md` for connection candidate/timeouts, GET header-versus-stream lifetime, client/trust snapshots and supported workload-credential refresh.

Exclusive locks:
- `dependency-profile-delivery`, shared with T4: root Cargo.toml/Cargo.lock, .dockerignore, build/docker/Dockerfile, template_profiles.json, changed-surfaces.sh and shared initializer/classifier fixtures. Start its carrier slice only after the prior writer releases it; preserve the integrated messaging slice.

Final validation:
- Claim: Native candidate fallback receives the existing timer; retry/finality and retained/removed object-storage profiles preserve their accepted contract.
- Checks: Matching assembled build/tests/docs and selected delivery/dependency/classifier route; CI owns selected heavy integration/image/initializer gates. No additional local gate.
- Observable: Healthy later same-family TCP candidate gets a dial opportunity under the unchanged outer bound; failures keep native classification and mutation ambiguity. Profile output retains source only when its provider is selected.

Reopen if:
The native source/settings shape differs materially or patch effects escape the
accepted consumers (Technical Design); scope/behavior must change (Definition).
