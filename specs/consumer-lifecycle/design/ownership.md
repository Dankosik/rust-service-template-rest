# Consumer lifecycle ownership map

Status: ready. This map applies `rust-coder`'s earliest-owner rule and
`rust-structural-quality`'s deletion test to [System Design](system.md).
Mechanically forced placement stays with the current owners; the only new
responsibilities are upgrade custody and source-only lifecycle proof.

The validation-row file list names existing owners, not permission to rewrite
them wholesale. Implementation uses the smallest edits those owners require;
new runtime proof cannot be repeated across all initializer matrix cells. The
source-only lifecycle carrier selects its finite retained tuple once.

Implementation containment clarification: source-only updater CLI/library and
proof are invoked from the admitted template checkout; the operational guide
is retained in generated consumers. This makes the already-selected execution
owner explicit without moving accepted baseline custody or changing the command
contract. The retained `image-results.py` is the implementation location of the
existing small native aggregate, not the rejected receipt verifier. These are
bounded placement/link-closure refinements; they neither expand portable
ownership nor create per-task review or proof gates. Keep portable carriers
usable when a consumer lacks these newly introduced non-portable files.

The accepted reuse rung for upgrade custody is existing Python standard-library
input code plus native Git; strongest rejected same-level maintained alternative
is Copier 9.18.2 because rendering/answers interoperability and retained baseline
custody still need a bridge. Parity is against the accepted U1–U4 outcomes and
actual full initialization. Reopen on a demonstrated lower-cost exact bridge.
The proof carrier reuses Compose and native PostgreSQL/NATS operations; its
custom portion is finite fixture ordering and assertions, not storage mechanics.

Rust production crate placement is untriggered. The fixtures remain in one
existing proof package; no new crate, dependency direction, service API or
runtime lifecycle boundary is introduced. Source-only containment is explicit
at one inventory owner, and isolated overlay identity is evidence, not generated
consumer truth. Root self-review of this ownership map found no surviving
placement fork; the conditional Rust Ownership Review panel is not selected.
Fresh Technical Design Review still inspects consistency and necessity of the
whole mechanism and this map.
