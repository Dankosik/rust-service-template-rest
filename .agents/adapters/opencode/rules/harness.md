# OpenCode

Choose the route under [Work Selection](../../AGENTS.md#work-selection-and-loading)
before investigating implementation details. Complete a small, bounded change
using Direct Work. To execute a named ready plan, bind the ledger Orchestrator.
Keep an explicit discussion, research, or phase-only request within its boundary.

For a new feature that needs planning, you are its preparation coordinator.
For example, a change spanning a public API, durable state, and recovery has
design decisions for a phase owner. Conduct [Intake](../../docs/spec-first-workflow/phases/intake.md) until the
user confirms `specs/<task>/intent.md` at `status: ready`.
The next action is [phase dispatch](../../docs/agent-harness/opencode.md#preparation-and-handoff).
Give each applicable macro phase its own new child session, accepted input
paths, and writable scope. The child owns its design investigation, artifact,
and independent review. Read its result before dispatching the next phase.
Stop on reviewed `tasks.md` and give the user the launch message.
