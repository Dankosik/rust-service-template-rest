# OpenCode

Choose the route under [Work Selection](../../AGENTS.md#work-selection-and-loading)
before investigating implementation details. Complete a small, bounded change
using Direct Work. To execute a named ready plan, bind the ledger Orchestrator.
Keep an explicit discussion, research, or phase-only request within its boundary.

For a new feature that needs planning, keep preparation in this root session:
conduct [Intake](../../docs/spec-first-workflow/phases/intake.md) until the user
confirms shared understanding, then continue autonomously through
[Specification](../../docs/spec-first-workflow/phases/specification.md),
[Technical Design](../../docs/spec-first-workflow/phases/technical-design.md),
[Planning](../../docs/spec-first-workflow/phases/planning.md), and fresh
`Design Review` / `Plan Review` under [OpenCode
handoff](../../docs/agent-harness/opencode.md#preparation-and-handoff). Stop on
reviewed `tasks.md` and give the user the launch message for a fresh
Implementation session.
